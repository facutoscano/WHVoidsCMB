# WHVoidsCMB

## Description
This repository contains the analysis pipeline for correlating catalogues of cosmic voids with CMB lensing maps. Voids are identified using the Sparkling code based on the Wen&Han cluster catalogue.

The aim is to extract, stack, and model the convergence signal around these cosmic voids, fitting theoretical profiles and comparing the underlying physics with gravitational lensing analysis in clusters.

## Usage and Data
**Important:** The raw data (FITS maps, original catalogs, and processed results) are not under version control. The code assumes that the data are located in a local external directory, whose *path* must be configured locally by each user before running the scripts.
